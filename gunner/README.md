# 横板射击 · 持枪动画集（nanzhu）

原素材里 19 个角色**只有 idle / walk / run / talk 之类的空手动作，没有任何枪的骨骼、插槽或贴图**。
这个目录在不动原始文件的前提下，给主角 `nanzhu`（46 骨 / 42 动画）注入了一套持枪骨骼与 14 条持枪动画，
并配了一个可操作的横板射击 Demo 用来验证手感。

## 怎么跑

```bat
cd /d "E:\BaiduNetdiskDownload\9dm Black Sheep\unpack"
python -m http.server 8766 --bind 127.0.0.1
```

打开 <http://127.0.0.1:8766/gunner/index.html>（必须走 HTTP，`file://` 下读不了 json/atlas）。

| 操作 | 作用 |
|---|---|
| `A` `D` | 走 |
| `Shift` + `A/D` | 跑 |
| `空格` | 跳 |
| 鼠标 | 瞄准（枪口实时跟随） |
| 左键 / 按住 | 射击（30 发，自动连发） |
| `R` | 换弹 |
| `E` | 枪托近战 |
| `H` | 收枪 / 拔枪 |
| `F` | 受击 | 
| `G` | 倒地（再按复活） |
| `↑` `↓` | 锁定瞄角（不用鼠标做对比测试） |

URL 参数：`?demo=1` 自动演示全套动作；`?bones=1` 显示骨骼与握点；`?scale=280&panup=170` 放大看上半身；
`?aim=-35` 固定瞄角；`?upper=upper_reload` 强制播某条动画；`?slow=1` 慢动作。

## 注入的骨骼 / 插槽 / IK

```
Spine2
└── aim_pivot        ← 持枪枢轴（挂在两肩之间，setup 角让它朝世界 +X）
    └── gun          ← 枪身，x = 持枪距离（默认 235）
        ├── grip_R   ← 右手握把点（右手 IK 目标）
        ├── grip_L   ← 左手护木点（左手 IK 目标）
        └── muzzle   ← 枪口（开火/火光/子弹的生成点）
```

- 新插槽 `gun` 插在插槽表里 `UpperArm_3_R` 之前 —— 枪先画、手后画，手指压在握把上。
- 数据里保留了 `ik_arm_R` / `ik_arm_L` 两条 IK 约束（导出到 Spine 编辑器或其它 runtime 时可用），
  但 Demo 运行时把它们的 `mix` 置 0，改用 `game.js` 里的解析解（见下），行为完全可控。

## "流畅自然"具体是怎么做的

1. **姿势交给 IK，不靠关键帧硬摆**：枪绕 `aim_pivot` 旋转，双手握点跟着枪走，
   `game.js` 用余弦定理解算大臂/前臂角度 → 任意瞄准角下肘部弯曲都合理，不会出现手臂穿模或僵直。
   （世界角转局部角时按 `skeleton.scaleX` 翻符号，所以左右转身后手臂不会反向。）
   肘部的两个解**按"肘部世界 y 更低"来挑**，而不是固定 ± 偏转 —— 后者在朝右时恰好朝下、
   一转到左边就变成朝上，手臂会甩到头顶。
2. **分层轨道**：`track0` 下半身（原 `idle/walk/run`）、`track1` 上半身（`upper_*`）、
   `track2` 开火。开火用 `MixBlend.add` + `mixDuration = 0` 纯叠加，所以"边跑边打"时
   跑动完全不被破坏，后坐是叠加上去的。
3. **循环动画首尾同值**：`upper_idle/walk/run/fall` 的每一帧序列都保证 `t=0` 与 `t=duration` 数值一致，
   不会出现循环跳帧。
4. **缓动而非线性**：所有关键帧都带贝塞尔曲线（`curve/c2/c3/c4`），
   冲击用 ease-out（快出缓收），预备动作用 ease-in。
5. **步频同步**：`upper_walk` / `upper_run` 的时长直接从原 `walk` / `run` 动画量出来（1.333s / 0.867s），
   bob 频率与脚步严格一致；`gun` 骨骼再反向摆一点做补偿，枪口比身体稳。
6. **瞄准与躯干解耦**：每帧先 `updateWorldTransform()` 读 `Spine2` 的世界角，再反推 `aim_pivot`
   的局部角，所以呼吸/走跑的躯干晃动**不会**让准星漂移；同时按俯仰角给躯干和头加少量跟随，
   往上抬枪时身体会后仰，不会"手举着、身子不动"。
7. **角度阻尼 + 最短弧**：瞄角按指数阻尼趋近目标，且走最短弧（`((Δ+540)%360)-180`），
   转身瞬间不会绕一大圈。
8. **转身**：`scaleX` 翻转配 0.14s 的收缩-展开过渡 + `upper_turn` 动画，避免镜像硬切。
9. **混合时长分级**：短促动作（落地/受击/近战）用 0.08–0.1s 快速切入，
   状态切换（走↔跑↔待机）用 0.16–0.2s，倒地 0.3s。
10. **换弹时双手权重分别控制**：右手松一点、左手完全离枪去掏弹匣，再按时间线回握，
    比纯动画时间轴好调。

## 调参（右侧面板 / `build_gun_anims.py` 顶部 `CFG`）

| 参数 | 位置 | 说明 |
|---|---|---|
| 肘部朝向 | 面板 | 默认「朝下」（选肘部更靠下的解）；特殊姿势想举肘就切「朝上」 |
| 瞄准阻尼 | 面板 | 越大跟手越紧 |
| 抵肩微调 / 持枪高度 | 面板 | 枪托底相对肩点的前后偏移（默认 +8，即托底压在肩窝）、枪在身体上的高度 |
| 枪大小 | 面板 | 60%~220%，默认 130%（约 884×331 骨架单位，身高 950 的 0.93 倍）；改的是附件世界尺寸，握点不动，所以手始终握在原位 |
| 角色缩放 | 面板 | 默认 0.095（身高约 180px） |
| `grip_l_off` / `muzzle` / `gun_w,h` | `CFG` | 左手握点、枪口、枪的基准尺寸 —— 换真枪贴图时改这里 |

### 枪的大小与抵肩（运行时自动联动）

改「枪大小」时，下面几项由 `game.js:fitGun()` 一起重算，不需要动 `CFG`：

- **枪托底始终压在肩点**：`gun.x = -(托底局部 x) + 抵肩微调`，所以枪放大时是往前长，不会戳进身体也不会离开肩膀
- **握点 / 枪口按枪图真实像素换算**（`GUN_PX`：托底 10、握把 85、护木 134、枪口 298）
- **握点自动受臂长约束**：肩→握点超过 `CHAIN - 100`（右）/ `CHAIN - 60`（左）时沿枪身回收，大枪也不会让手臂拉直脱节
- 改尺寸后必须调 `attachment.updateOffset()`，否则 Spine 3.8 的顶点不刷新 —— 表现为「拖滑块画面没反应」

改完 `CFG` 重新 `python build_gun_anims.py` 即可；只调面板参数则刷新页面就生效。

## 已知限制

- **没有枪的美术资源**：Demo 里的枪是程序化画的示意图；换成正式枪需要替换贴图与 `CFG` 里的尺寸。
- **角色贴图是正面站姿**（原美术如此），横板观感靠"朝左/朝右翻转 + 手臂 IK"实现，
  严格侧身需要美术侧再出一套侧视贴图。
- HUD 里的 `脚底/地面`（脚踝世界 y，正常在 0 附近）和 `手臂 IK`（解算残差，正常 <1px）
  是开发调试信息，正式接入时删掉 `hud()` 里那两行即可。
- 骨骼数量少（46 骨、无 IK 用骨骼、无手指骨骼），所以**下垂的手腕旋转靠固定角**（`hand_r_rot`），
  极端角度下手掌朝向会不够准确。
- 大幅向上抬枪（>60°）时，袖子网格会被拉伸 —— 这是原美术蒙皮权重的限制，
  正式项目建议出枪时重做手部权重，或把瞄角限制在 -70°~+45°。
- 空中没有专门的下半身动画，Demo 用 `run` 放慢 + 定格模拟腾空动作；
  正式做建议按 `upper_jump/upper_fall` 的命名补一对 `jump/fall` 全身动画。
- 每帧调用两次 `updateWorldTransform()`（瞄准 + 手臂解算），46 骨骨架开销可忽略，
  但换成 300+ 骨的 BOSS 骨架时建议缓存或用 Spine 的 IK 约束（数据里已经留好）。
